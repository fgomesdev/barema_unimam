BAREMA DA FACULDADE UNIMAM

Este projeto foi desenvolvido com o objetivo de auxiliar os alunos da UNIMAM no acompanhamento de suas Atividades Complementares.

A ideia surgiu a partir da dificuldade de realizar o cálculo das horas sem depender diretamente da coordenação. 
A partir da análise do Barema da faculdade, desenvolvi esta calculadora para facilitar a conferência das atividades e permitir que os alunos compreendam
quantas horas já possuem e quantas ainda faltam para concluir as Atividades Complementares necessárias para a formação.
Após o enviar os certificados o aluno pode gerar o pdf(com todos os certificados que ele enviou) e encaminhar para coordenação para analisar a validade deles.
